Emergency Password Reset CRITICAL ACCESS

Use this operation if administrators are locked out of the RupeeCRM business application.
Executing this resets the internal configuration flag auth_enabled = false in the database. Users will be able to access the business application without entering a password.

Controlled Application Restart SUPERVISOR SUPERVISED

Signals the active JVM process to gracefully terminate with exit code 10.
The Simple-Billing launcher supervisor process will intercept exit code 10 and automatically restart the application within seconds.
